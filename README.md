# 🛒 AuraWear - AI-Integrated MERN E-commerce Store

<div align="center">

![AuraWear E-commerce](https://img.shields.io/badge/AuraWear-E--commerce-black?style=for-the-badge&logo=shopify&logoColor=white)

A modern, highly premium **full-stack e-commerce clothing website** built with **React**, **Node.js**, **Express**, **MongoDB**, and **Tailwind CSS**. Features a custom-built **AI Semantic Smart Search** using Local LLM Embeddings and Cosine Similarity to find products by meaning rather than just exact keywords.

## ✨ AI Integration

### 🧠 Semantic Smart Search (Powered by AI)
- Uses **@xenova/transformers** (Xenova/all-MiniLM-L6-v2) in the Node.js backend to generate 384-dimensional vector embeddings for all products.
- Uses **Cosine Similarity** math algorithm to match user queries with products based on context and meaning (e.g. searching "winter clothes" brings up jackets).

## ✨ Features

### 🛍️ Customer Features
- 🌗 **Dynamic Theme** - Clean Minimalist Day/Night mode toggle.
- 🔐 **User Authentication** - Secure Login & Registration using JWT.
- 🛒 **Shopping Cart** - Advanced multi-variant cart logic (sizes, quantities).
- 🔍 **AI Smart Search** - Find Products Instantly via Natural Language.
- 🏷️ **Category Filter** - Men, Women, Kids.
- 💰 **Price Sorting** - Low to High, High to Low.
- 📦 **Order Placement** - Easy Checkout Process.
- 📱 **Fully Responsive** - Premium Mobile & Desktop UI.

### 👨‍💼 Admin Features
- 📊 **Admin Dashboard** - Complete Control Panel.
- ➕ **Add Products** - Upload New Items with Images (Auto-generates AI Embeddings on upload).
- 📋 **Product List** - View & Manage All Products.
- 🖼️ **Cloudinary Integration** - Cloud Image Storage & Transformation.
